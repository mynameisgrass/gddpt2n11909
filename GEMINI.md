## 1. SEO Optimization for Google Search

### Metadata API (Next.js)
This project uses Next.js's built-in Metadata API to generate optimal tags for Google Search:

```typescript

  openGraph: { ... },
  twitter: { ... },

```

### Structured Data (JSON-LD)
The site embeds `Article` and `FoodEstablishment` schema.org structured data, enabling Google Rich Snippets:
- Recipe cards for Phở Bò Hà Nội
- Cultural article markup for the scrollytelling narrative

### Core Web Vitals Alignment
Google Search ranking factors include Core Web Vitals. This project targets:
| Metric | Target | Strategy |
|--------|--------|----------|
| LCP | < 2.5s | Server-rendered hero text, optimized images |
| FID | < 100ms | Minimal main-thread JS, deferred animation hydration |
| CLS | < 0.1 | Explicit image dimensions, font `display: swap` |
| INP | < 200ms | Event handlers use `requestAnimationFrame` batching |

## 3. Google Fonts Integration

### Fonts Used
- **Playfair Display** — Elegant serif for headlines and Vietnamese diacritics.
- **Inter** — Clean sans-serif for body text.

### Loading Strategy
```typescript
import { Playfair_Display, Inter } from "next/font/google";

const playfair = Playfair_Display({
  subsets: ["latin", "vietnamese"],
  display: "swap",
  variable: "--font-playfair",
});
```
- `next/font/google` handles automatic self-hosting (no external requests to fonts.googleapis.com).
- `display: "swap"` prevents invisible text during font loading.
- Vietnamese subset ensures diacritics render correctly.

## 4. Future Google Cloud / Firebase Integration Paths

### Firebase Hosting
- Next.js can deploy to Firebase Hosting with Cloud Functions for SSR.
- Command: `firebase init hosting` → configure `next.config.js` for Firebase adapter.
- Benefits: Global CDN, automatic SSL, preview channels for staging.

### Firebase Analytics
- Integration point: Add `firebase/analytics` SDK in `layout.tsx`.
- Track scroll depth per section (Hero → Bento → Parallax → Conclusion).
- Custom events: `section_view`, `scroll_depth_50`, `scroll_depth_100`.

### Google Cloud Vision API (Future Enhancement)
- Could analyze uploaded food images for automatic dish identification.
- Endpoint: `vision.googleapis.com/v1/images:annotate`
- Use case: User uploads a photo → AI identifies "Phở Bò" → shows relevant section.

### Google Cloud Translation API
- Potential for multi-language support (Vietnamese ↔ English ↔ Japanese).
- The scrollytelling narrative could adapt dynamically based on `Accept-Language`.

### Google Search Console
- Submit `sitemap.xml` (auto-generated by Next.js) to Google Search Console.
- Monitor indexing status, search queries, and click-through rates.

## 5. Deployment Recommendations

### Option A: Vercel (Recommended for Next.js)
- Zero-config deployment with `vercel deploy`.
- Edge Functions for SSR closest to Vietnamese users (Singapore/Tokyo edge).
- Built-in Web Analytics dashboard.

### Option B: Google Cloud Run
- Containerized Next.js deployment.
- `Dockerfile` → `gcloud run deploy --region=asia-southeast1`.
- Integrates natively with Firebase, Cloud CDN, and IAM.

### Option C: Firebase Hosting + Cloud Functions
- Static assets on Firebase CDN; SSR via Cloud Functions.
- Best for projects already in the Google ecosystem.
